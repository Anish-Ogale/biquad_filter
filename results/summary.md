# Pre-layout feasibility prototype summary — clock-programmable differential SC biquad (Sky130)

Pre-layout, simulation-only feasibility prototype for the Chipalooza
Challenge #4 proposal. This is preliminary behavioral verification plus a
transistor-level op-amp proof-of-concept, **not** a completed transistor-level
biquad or the final IC implementation. Everything here is **[SIM]** (ngspice
47), **[ANALYTICAL]** (exact discrete-time model, closed form) or **[EST]**
(estimate, method stated). Repo: `README.md` lists what is simulated versus
planned; per-spec verdicts in `results/spec_check.md`. The CSV files referenced
below are committed snapshots under `results/data/`, regenerated by the make
targets; the Markdown summaries and plots are the readable evidence.

## Q evidence guide
- `results/behavioral/q_evidence.md` section (a): real op-amp corners, differential Q error.
- Section (b): targeted Q≤2 / 18 dB A0/GBW sweep.
- Section (c): step-ring vs multisine method check; K=200/Q=5 step-ring residual is not confirmed.

## Headline numbers

- **Cap budget [ANALYTICAL]**: CI = 8 pF; total 33.6-68.7 pF at 0 dB and
  37.2-117.6 pF at 18 dB over all 32 (K, Q), within the adopted <=120 pF
  target. MiM area max **0.0585 mm2** vs the 0.12 mm2 spec (MiM only;
  switches, op-amps, bias and routing excluded). Worst quantization
  f0 +1.24 % (K=200/Q=5) and Q +0.98 % (K=200/Q=2.83).
- **Gain steps [SIM]**: LP gain 0/6/12/18 dB by Cs1 = G*Cs; worst gain error
  **0.060 dB** over ideal/tt/ss op-amp sets, inside the ±0.5 dB typ target.
  At 18 dB the real tt/ss op-amps show Q errors of -11.2/-11.9 % at
  K=100/Q=5 (inside Q>2 max ±20 %, outside the ±5 % sweep criterion).
  One ss/K=25/Q=1/18 dB step-ring f0/Q fit did not converge; its gain error
  is still valid from the settled LP tail.
- **Behavioral map check [SIM]**: the sampled LP/BP step response matches the
  exact discrete map to **<=0.09 % of the output peak** for K=50/Q=1,
  K=25/Q=0.5 and K=200/Q=5 (`results/plots/fig_step_response.png`).
- **Behavioral op-amp requirement [SIM]**: all three sweep cases
  (K=100/Q=5, K=25/Q=1, K=200/Q=5) at both gains support **A0 >= 60 dB and
  GBW >= 5 MHz** under the differential-Q limits. At 0 dB alone the minimum
  is lower (A0 >= 49 dB, GBW >= 3 MHz). The K=200/Q=5 step-ring extraction
  gives Q -14.8/-15.1 % at 80 dB/10 MHz, but the multisine cross-check (+0.5 %)
  does not confirm it; treat it as a step-ring extraction artifact pending
  transistor-level measurement.
- **Q<=2 at 18 dB [SIM]**: at the 49–50 dB transistor corners the differential
  Q error is 5.0–6.3 % (K=25/Q=2, K=200/Q=2), outside the ±5 % typ row. The
  targeted A0/GBW check gives **1.9 % worst at A0=60 dB**, almost independent
  of GBW from 7.82 to 20 MHz; the existing 60 dB A0 requirement covers it
  (`results/behavioral/q_evidence.md` section b).
- **Noise [EST]**: sampled kT/C only, both halves/all branches: 66.7 µVrms
  worst at 0 dB and 87.2 µVrms at 18 dB (K=25/Q=0.5). Excludes 1/f, op-amp,
  THD and clock-feedthrough terms.
- **Multisine extraction [SIM]** (K=100/Q=5, 10 tones, ideal op-amp):
  f0 +0.30 %, Q -3.36 % vs target. The step-ringing fit gives +4.2 % Q
  error at the ideal 80 dB/10 MHz point, but degrades to -11.2/-11.9 % at
  18 dB with real tt/ss op-amps. The K=200/Q=5 step-ring value (-14.8/-15.1 %
  at 80 dB/10 MHz) is not confirmed by multisine (+0.5 %) and is treated as
  an extraction artifact pending transistor-level measurement; it remains
  inside the Q>2 max ±20 % on the step-ring method.
- **Offset [SIM]** (5 mV on both op-amps, same and opposite signs, 0 and
  18 dB, 80 baseline runs, no rail): worst **29.4 mV** at 0 dB / Q<=2 /
  all K (adopted max 40 mV) and **45.5 mV** over all gain/Q (adopted max
  60 mV), i.e. offset gains of about 5.9x and 9.1x. Real tt/ss worst-case
  reruns are 35.3/34.0 mV; the ideal 80 dB case is 53.5 mV. The offset is
  **not** gain-invariant.
- **Transistor-level op-amp [SIM]** (CL = 16 pF/side): tt 27 C: 50.0 dB /
  10.6 MHz / PM 56.3 deg / **578 uA**; ss 110 C 2.97 V: 49.0 / 7.82 /
  52.1 / 485 uA; ff -40 C 3.63 V: 50.5 / 13.94 / 61.6 / 687 uA. tt/ff meet
  the 50 dB and 10 MHz minimums; **ss misses both**, and all three are below
  the 60 dB A0 needed at 18 dB gain. The **80 dB gain target is not met**.
  Chip IDDA estimate: 2 x 578 uA + 60 uA replica = **1.22 mA typ** vs the
  adopted 1.3 mA typ / 2.0 mA max spec.

## Toolchain notes (traps that cost time; read before re-running)

1. ngspice `ph()`/`cph()` on complex vectors return wrong values on this
   build; `wrdata` the raw complex vector and unwrap `atan2` in numpy.
2. xschem netlist output wraps the top cell in `**.subckt` comments and a
   trailing `.end`; both must be fixed before ngspice can include it
   (`design/opamp/opamp_2stage.spice` is the fixed committed copy).
3. Capacitor device values that are parameters must be braced (`{CI}`) or
   they silently become 0 F.
4. High-Q settling is slow: settle cycles ~ ln(0.02)/ln(r), r =
   exp(-theta/2Q) (K=200/Q=5: ~1250 cycles). All settled-state benches size
   `tstop` from the pole radius.
5. ngspice model load is ~10 s per invocation; batch analyses per deck.
6. Element names must start with the type letter under ngbehavior=hsa;
   lowercase `v()` in B-sources; ns-suffix rise/fall in PULSE.

## Spec-check snapshot

Full table with verdicts and the adopted-adjustments section:
`results/spec_check.md`. Adopted changes: f0 typ ±1.5 % at K=200, IDDA
1.3/2.0 mA, offset max ±40/±60 mV, cap target ≤120 pF. The ss op-amp corner
still misses the 50 dB/10 MHz minimums and all corners miss the 60 dB A0
needed at 18 dB (including the Q<=2 row); these are reported as limitations,
not relaxed silently. Figure provenance and current values are listed in
`results/plots/README.md`.
